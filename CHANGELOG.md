# Changelog

## [1.0.0] - 2026-09-23

Первый публичный выпуск.

- Таблица переводов: ключ и строка на каждый язык проекта, языки берутся из настроек JTL SDK.
- Компонент `LocalizedText` для TextMeshPro: подставляет перевод при включении и при смене языка, умеет менять только шрифт.
- Шрифты по языкам: наборы шрифтов с поправкой размера и своим шрифтом на конкретном тексте.
- Окно `JTL SDK › Localization`: правка таблицы с поиском по ключам и переводам, проход по открытым сценам, экспорт и импорт CSV, автоперевод пустых строк через Google Translate без внешних зависимостей.
- `Localization.Translate(key)` для строк, которые собираются в коде.
